The model judges each flow on its own shape, so it cannot see an attack that is only visible in aggregate — a botnet whose every request looks ordinary, or a link that falls silent. This page asks the other question: is this normal for this network, at this hour, on this kind of day. It compares against what it has learned here, not a fixed threshold, which is why a busy Monday morning does not read as an attack.
